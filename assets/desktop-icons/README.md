# Ícones da área de trabalho

Todos os ícones desta pasta são arquivos PNG reais. Eles não dependem de CSS nem de SVG embutido.

Substitua qualquer PNG por outra imagem com o mesmo nome e recarregue o ProdutivOS.

Para usar JPG, JPEG, WebP ou GIF, coloque o arquivo nesta pasta e altere seu nome na tabela `DESKTOP_ICON_FILES`, no início de `app.js`.

Recomendação: PNG transparente, quadrado, entre 48×48 e 128×128 pixels. Se um arquivo não existir, o sistema usa automaticamente o ícone desenhado no código.
